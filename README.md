  <h1>📚 BookHive – Library Management System</h1>
  <p><a href="http://bookhivelms.infinityfree.io/" target="_blank">Visit BookHive – Library Management System</a></p>
  <p>For the best experience, please view this page on a desktop device.</p>

  <p>A modern, lightweight, PHP-based library system with 3D UI elements using Spline.</p>

  <h2>🚀 Overview</h2>
  <p>BookHive is a beginner-friendly yet feature-rich Library Management System built using:</p>
  <ul>
    <li>PHP (Core functionality)</li>
    <li>MySQL (Database)</li>
    <li>HTML, CSS, JS (Frontend)</li>
    <li>Spline (3D animations & UI elements)</li>
  </ul>
  <p>This project was built as a first major web development project and includes all essential library operations like logging in, searching books, borrowing, returning, and generating receipts.</p>

  <h2>🌟 Features</h2>

  <h3>🔐 User Authentication</h3>
  <ul>
    <li>Login / Signup using PHP + MySQL</li>
    <li>Password validation</li>
    <li>Session handling</li>
    <li>Secure login flow</li>
  </ul>

  <h3>🏠 User Dashboard</h3>
  <ul>
    <li>Displays account details</li>
    <li>Shows borrowed books</li>
    <li>Quick navigation to all major features</li>
  </ul>

  <h3>🔎 Search Books</h3>
  <ul>
    <li>Search by book name or category</li>
    <li>Fast SQL-based filtering</li>
    <li>Clean UI with instant results</li>
  </ul>

  <h3>🤖 BookBot (FAQ Assistant)</h3>
  <ul>
    <li>A simple inbuilt chatbot that contains:
      <ul>
        <li>Predefined FAQs</li>
        <li>Basic question matching</li>
        <li>Helps users understand features (not AI-based)</li>
      </ul>
    </li>
  </ul>

  <h3>📚 Borrow & Return Books</h3>
  <ul>
    <li>Borrow a book</li>
    <li>Check availability</li>
    <li>Track due dates</li>
    <li>Return books</li>
    <li>Auto-update database</li>
  </ul>

  <h3>🧾 Receipt Generator</h3>
  <ul>
    <li>Generates a receipt after borrowing</li>
    <li>Shows user details, book details, and date</li>
  </ul>

  <h3>🖼️ 3D Spline Integration</h3>
  <ul>
    <li>Animations on the homepage</li>
    <li>Visual UI improvement</li>
    <li>Interactive components</li>
  </ul>

  <h3>🎨 Clean UI</h3>
  <ul>
    <li>Customized CSS and simple layout for students and beginners</li>
  </ul>
